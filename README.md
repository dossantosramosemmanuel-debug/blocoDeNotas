# blocoDeNotas

Projeto Piloto: Um Bloco de Notas Simples para Ensinar `eventListener` e `localStorage`.

## Funcionalidades

- Salva automaticamente o texto digitado no `localStorage`.
- Mantém o conteúdo preservado mesmo após recarregar a página.
- Permite limpar a nota com um botão dedicado.
- Exibe status acessível de salvamento e erros.

## Uso

1. Abra `index.html` no navegador.
2. Digite no campo de notas.
3. O texto será salvo automaticamente.
4. Use o botão "Limpar notas" para remover o conteúdo salvo.
